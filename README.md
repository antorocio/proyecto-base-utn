#### Proyecto para el Curso de Programador Web Inicial de la UTN

# Maquetación Web estilo WhatsApp

## Introducción
Este proyecto consiste en una maquetación en HTML y CSS.

La interfáz para el usuario es de tipo WhatsApp, comenzando con un sidebar que contiene una lista de chats y luego un panel principal con la conversación seleccionada.

Se utilizó solo HTML y CSS, sin JavaScrip.

## Estructura del proyecto 

* /assets/  (ímagenes)
* /index.html
* /styles/main.css

## Vizualización

Abrir el archivo **index.html** en un navegador.

## Desiciones de diseño/consideraciones

* Los colores utilizados fueron extraidos del modelo, con una paleta de colores similares a la app de WhatsApp.
* Se utilizó *Flexbox* que permitió organizar elementos de manera flexible, facilitando la distribución del espacio y la alineación de los ítems dentro de un contenedor padre. También se utilizó *grid* que permitió dividir contenedores en áreas, dando la pisibilidad de adaptar el diseño a dispositivos móviles, tablets y escritorio, ya que los elementos se "flexibilizan".
